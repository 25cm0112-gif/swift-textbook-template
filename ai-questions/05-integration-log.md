使用した生成AIツール
使用ツール： Gemini

質問と回答の記録
質問：
SwiftUI、SwiftData、MapKit、PhotosUIを連携させて、撮影・選択した写真を位置情報と一緒に地図上と一覧で管理できる「フォトマップアプリ」の総合的なサンプルコードを作成してください。

AIの回答の要点：

データモデル設計: SwiftDataの @Model を使用し、タイトル、メモ、緯度・経度、画像データ（Data? 型）を永続化する PhotoRecord クラスを作成。
位置情報の取得: @Observable マクロと CLLocationManagerDelegate を組み合わせた現代的な LocationManager を実装し、非同期で現在地を追跡。
地図とデータの統合: 新しい MapKit 構文の Map を用い、保存されたレコードを Annotation としてループ処理し、写真付きのピンを地図上に動的配置。
写真の選択と保存: PhotosUI の PhotosPicker を利用し、選択された画像を Transferable を経由して Data 型に変換し、SwiftDataのモデルコンテキストに挿入（永続化）する一連の流れをコンポーネント化。

自分の理解：
これまで個別に学んできた「データの保存（SwiftData）」「マップ表示（MapKit）」「メディア取得（PhotosUI）」が、どのように一つのアプリとして結びつくのかがコード全体を通して非常によく理解できた。特に、画像の生データをそのままSwiftDataに入れるのではなく Data? 型で保持し、computed property（計算プロパティ）を使って UIImage に変換してビューに表示するというアプローチは、データの軽量化と型安全性の両面で理にかなっていると納得した。

質問：
MapKitの新しい構文において、地図上に独自の画像（写真のサムネイルなど）を丸型で表示するカスタムピン（注釈）を実装するにはどうすればよいですか？

AIの回答の要点：

従来の Marker ではなく Annotation コンポーネントを使用する。
Annotation(title, coordinate) のクロージャの中に、通常のSwiftUIビュー（Image など）を記述することで自由に見た目をカスタムできる。
写真データが存在する場合は、.resizable().aspectRatio(contentMode: .fill) でトリミングし、.clipShape(Circle()) や .overlay を重ねることで綺麗な丸型アイコンに仕上がる。

自分の理解：
Marker は標準のバルーン型アイコンしか出せないが、Annotation を使えば完全に自由なSwiftUIのコンポーネントを地図上に配置できることが分かった。ボタンとして実装することで、タップ時に詳細画面のシート（.sheet(item:)）を開くトリガーにできる仕組みも非常に実用的だと感じた。


質問：
SwiftDataで保存したレコードを一覧表示し、スワイプで削除できるようにする手順と、モデルコンテキストからの削除方法について教えてください。

AIの回答の要点：

@Query マクロを使って、並び替え条件（例：作成日時の降順 order: .reverse）を指定してデータを自動取得する。
List と ForEach を組み合わせ、ForEach に .onDelete モディファイアを付与する。
.onDelete のクロージャ内で、modelContext.delete(records[index]) を呼び出すことで、永続化データ層から対象のオブジェクトを削除する。

自分の理解：
SwiftUIの List が持つスワイプ削除の仕組み（.onDelete）と、SwiftDataの modelContext.delete の連携が驚くほどシンプルに書けることに感動した。CoreDataの時代に比べて、コンテキストへの反映や画面の自動更新（リアクティブな挙動）のコード量が劇的に減っていることが体感できた。
